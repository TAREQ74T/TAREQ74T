# Polish BC-007 — تحسينات بصرية محدودة

## الغرض

أربع نقاط بصرية فقط دون أي تغيير وظيفي أو قرآني، استعدادًا لبناء APK:

1. قائمة السور بسطر واحد.
2. تحسين وضوح زر الإعدادات (الترس).
3. تدرج هادئ وزخرفة CSS لشاشة البداية.
4. فاصل About متعدد الألوان.

## القرارات المعمارية

- **قائمة السور: سطر واحد = الرقم + الاسم العربي فقط.**
  - عودة إلى البنية الأصلية (BC-001) بعد أن أضاف BC-002 الترجمة الإنجليزية
    كسطر ثانٍ داخل عمود `.surah-names`.
- **الاسم الإنجليزي `name_en`: يبقى في البيانات وفي البحث، ولا يُعرض في القائمة فقط.**
  - مبرر الإبقاء عليه في البحث: المستخدم اللاتيني يبحث باسم السورة بالإنجليزية،
    وتظهر الترجمة في نتائج البحث وتذييل آية السورة؛ القائمة بذاتها واجهة عربية خالصة.
- **Splash: تدرج + زخرفة CSS فقط — لا GIF.**
- **الفاصل: عنصر CSS بحت متعدد الألوان.**
- كل التعديلات بصرية؛ لم يُلمس `quran_full.json` ولا أي نص قرآني ولا `package.json`.

## تفاصيل التنفيذ

### 1) قائمة السور بسطر واحد

- `src/components/quran/SurahList.tsx`: أُزيل غلاف `.surah-names` وسطر `.surah-name-en`.
  أصبح الصف `surah-number` + `surah-name` فقط (مطابق لبنية Genesis).
- `src/index.css`:
  - حُذفت قواعد `.surah-names` (التكديس العمودي) و`.surah-name-en`
    وقاعدة الوضع الليلي `:root[data-theme='dark'] .surah-name-en`.
  - `.surah-name` أصبح مرنًا مع شبكة أمان: `flex:1; min-width:0; white-space:nowrap;
    overflow:hidden; text-overflow:ellipsis`.
  - القياس: الاسم الأقصى عرضه الطبيعي ≤75px مقابل ~197px متاحًا في الشريط الجانبي
    الثابت 260px، فلا يحدث اقتطاع فعلي؛ الـ ellipsis وقاية فقط.

### 2) زر الإعدادات (الترس)

- الترس موجود أصلًا كـ SVG قياسي (`QuranPage.tsx` → `.sidebar-gear-btn`).
- التحسين CSS فقط في `src/index.css`: خلفية `var(--green-100)` مرئية في الوضعين
  + حدود `var(--green-700)` + أبعاد أكبر قليلًا (2.25rem) + ظل خفيف.
- اللونان متغيران من الثيم فيتأقلمان تلقائيًا مع الليلي/النهاري.

### 3) Splash

- `src/components/splash/SplashScreen.tsx`: الأيقونة داخل حاوية زخرفية
  `.splash-screen__badge` (تُبنى زخرفتها عبر pseudo-elements).
- `src/index.css`:
  - خلفية `background-color: var(--green-900)` ثابتة كاحتياط للمتصفحات القديمة
    + `background-image` بطبقتين `radial-gradient` ذهبيتين خافتتين
    + `linear-gradient(150deg)` من الأخضر الداكن إلى درجة أفتح.
  - الزخرفة: حلقة رفيعة فاتحة + حلقة ذهبية منقطة حول الأيقونة.
  - `pointer-events: none` على الحاوية الزخرفية فلا تعترض النقر/التخطي.
  - لم تتغير النصوص ولا آلية الاختفاء التلقائي (1.8 ثانية) ولا رقم الإصدار.

### 4) فاصل About

- `src/components/about/AboutScreen.tsx`: داخل الفاصل الحالي `.about-ornament`
  أُضيفت حبيبة وسطية `.about-ornament__gem`.
- `src/index.css`: إعادة تلوين خطوط الفاصل بتدرج متعدد الألوان
  (أخضر `var(--green-700)` ← ذهبي `rgba(201,162,39,.9)` ← شفاف)،
  والحبيبة معيّن مائل بإطار `var(--gold)` وخلفية `var(--green-100)`.
- لم يتغير سطرا الدعاء ولا سطر الإنشاء ولا رقم الإصدار.
