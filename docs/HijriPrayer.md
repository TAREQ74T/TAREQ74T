# HijriPrayer — التاريخ الهجري وأوقات الصلاة (BC-003)

## 1. خوارزمية حساب أوقات الصلاة والمصدر

- **المصدر:** مكتبة [adhan](https://github.com/batoulapps/adhan-js) (الإصدار 4.4.3) — الحسابات الفلكية وفق خوارزميات "Astronomical Algorithms" لـ Jean Meeus.
- **طريقة الحساب الافتراضية:** رابطة العالم الإسلامي (**MWL** / MuslimWorldLeague) — قرار معماري مقفل من MASTER_INDEX.
- **المذهب الافتراضي:** الشافعي (قابل للتبديل إلى الحنفي عبر الواجهة).
- **الإحداثيات:** خط العرض/الطول من `navigator.geolocation` (تلقائي) أو إدخال يدوي. الافتراضي: **مكة المكرمة** (21.4225°, 39.8262°).
- **الصلوات الست المعروضة:** الفجر، الشروق، الظهر، العصر، المغرب، العشاء.

### معالجة المناطق الزمنية (مهم)

adhan يعيد `Date` بقيم **UTC** للحظة الصلاة الحقيقية (يبنيها عبر `Date.UTC`). لعرض وقت الموقع المحلي بغضّ النظر عن توقيت جهاز المستخدم:

- تُحسب إزاحة الموقع من خط الطول: `longitudeOffsetMinutes = round(longitude / 15) * 60`.
- تُعرض الأوقات بإضافة هذه الإزاحة إلى لحظة الصلاة ثم قراءة حقول UTC:
  `formatPrayerTime(date, offset)` = `(date + offset)` بقراءة `getUTCHours/getUTCMinutes`.
- لتحديد "التاريخ الهجري" لموقع مختلف عن توقيت الجهاز، تُعدَّل ساعة الأساس بإزاحة الفرق بين الموقع والجهاز قبل تمريرها لخوارزمية اليوم الشمسي.

مثال تحقق: مكة (UTC+3) في 2024-01-01 بطريقة MWL → الفجر 05:39، الشروق 06:58، الظهر 12:25، العصر 15:29، المغرب 17:50، العشاء 19:04 — مطابقة للمراجع المنشورة.

## 2. منطق الإزاحة الهجرية

- **المصدر:** `Intl.DateTimeFormat('ar-SA-u-ca-islamic-umalqura', ...)` — تقويم أم القرى الهجري عبر واجهة المتصفح القياسية، **دون أي مكتبة إضافية** (قرار معماري).
- **الإزاحة:** `type HijriOffset = number` من **−3 إلى +3** أيام.
  - `getAdjustedHijriDate(base, offset)` = نسخة من الأساس + `setDate(getDate() + offset)`.
  - تُحفظ في `localStorage` تحت المفتاح `mushaf-al-huda:hijriOffset`.
- **الشارة:** عند إزاحة غير صفرية تُعرض شارة ("+2 يوم" / "−3 يوم") بجانب التاريخ.
- **التخزين:** `src/storage/adjustments.ts` (قراءة/كتابة/إعادة ضبط مع `clamp` للنطاق).
- **الانعكاس:** التاريخ الهجري محسوب من `useHijriDate` داخل مكوّن `HijriDateDisplay`، وأي موضع عرض يستخدم `hijri.adjustedDate`/`hijriString` يعكس الإزاحة تلقائياً.
- **Fallback:** إذا لم يدعم المتصفح تقويم islamic-umalqura تظهر رسالة واضحة بدلاً من كسر الواجهة.

## 3. منطق تعديلات الصلوات الفردية

- **النوع:** `type PrayerKey = 'fajr' | 'sunrise' | 'dhuhr' | 'asr' | 'maghrib' | 'isha'`.
- **التعديل:** `type PrayerAdjustments = Record<PrayerKey, number>` بالدقائق من **−30 إلى +30**.
- **الدالة:** `adjustTime(base, minutes)` = `new Date(base.getTime() + minutes * 60_000)`.
- **العرض:** الوقت المعدَّل بارزاً بلون مميز، والوقت الأصلي المحسوب بجانبه كمرجع صغير متشطَّب.
- **التخزين:** تحت المفتاح `mushaf-al-huda:prayerAdjustments` مع `clamp` لكل صلاة.
- **إعادة الضبط:** زر "إعادة ضبط جميع تعديلات الصلوات" يعيد كل القيم إلى 0 (الوقت الأصلي المحسوب).

## 4. تغيير طريقة الحساب / المذهب

- الواجهة تعرض قائمة بطرق الحساب المدعومة من adhan (MWL، الهيئة المصرية، كراتشي، أم القرى، ...) واختيار المذهب (الشافعي/الحنفي).
- أي تغيير يعيد الحساب فوراً **مع الحفاظ على تعديلات المستخدم** (الـ adjustments تطبيقية بعد الحساب، غير مرتبطة بالطريقة).

## 5. الحالات الحدّية (Edge Cases)

| الحالة | المعالجة |
|--------|----------|
| رفض المستخدم صلاحية الموقع | رسالة + التحول للإدخال اليدوي أو البقاء على مكة |
| إحداثيات غير صالحة | رسالة "إحداثيات غير صالحة" |
| خطوط العرض العليا | قيم محسوبة من قاعدة adhan (High Latitude Rule) أو "—" للقيم غير المحددة |
| تعديل الهجري خارج ±3 | `clamp` + تعطيل الزر + تنبيه "وصلت الحد الأقصى" |
| تعديل صلاة خارج ±30 | `clamp` + تعطيل الزر |
| localStorage تالف/محذوف | التهيئة الافتراضية صفر |
| تغيير الطريقة/المذهب | إعادة حساب فوري مع بقاء التعديلات |
| عدم دعم Intl الهجري | رسالة fallback |
| تجاوز منتصف الليل | مؤقت يحدّث التاريخ والأوقات كل دقيقة مع بقاء الإزاحات |
