# Splash BC-011

## تحسين مفوَّض — §4b

نص طارق الحرفي:
"كان كتابًا بصورة مختلفة عن الآن ولا زال كتابًا مع إطار مزخرف ليس أكثر".

تعديل النطاق: §4.4 في العقد v1.1 كان يحدد "محدَّد نهائيًا: fade 400ms + نبض 2s". §4b يُوسّع: كشف clip-path 800ms + شعاع مرة واحدة 700ms + نبض 2.5s. التعديل مصدره رفض طارق البصري بتأريخ 28/9/2026.

## تحسين مفوَّض — §4c

نص طارق الحرفي:
"أتوقع مشهد مصحف مفتوح حقيقي".

الأيقونة: مشهد مصحف مفتوح 96px على حامل خشبي (صفحتان شبه منحرف، جلد #8B4513، علام أحمر، هالة ذهبية). الحلقتان أخف (نبض حول opacity 0.4). الحركات كما في §4b دون تغيير.
